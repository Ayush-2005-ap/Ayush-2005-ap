### 🤖 SyllabusAI — Deep Dive

> An AI-powered mobile academic companion built for students.

- 📚 **RAG Chatbot** — LangChain + FAISS/ChromaDB over syllabus PDFs for context-aware Q&A
- 📝 **PYQ Analysis** — Pattern detection across previous year questions
- 🎯 **Adaptive Quizzes** — Personalised based on weak areas
- 📅 **Study Schedules** — Auto-generated, deadline-aware timetables
- 🛠 **Stack:** React Native + Expo · Node.js + Express · Python + Flask · MongoDB Atlas · Render
